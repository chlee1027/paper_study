# experiments — 직접 돌려 본 것

실험 하나에 폴더 하나다.

```
experiments/
  <짧은_이름>/
    README.md        templates/experiment.md 를 복사해 채운다
    <노트북>.ipynb    돌린 것. 출력을 지우지 않고 넣는다
    results/         결과 CSV
    figures/         그 실험이 만든 그림
```

## 규칙 넷

1. **질문과 가설을 돌리기 전에 `README.md`에 적는다.** 돌린 뒤에 적으면 결과에 맞춰 질문이 바뀐다.
2. **노트북은 출력을 살려서 넣는다.** 출력이 없으면 그 실행이 실제로 돌았다는 근거가 사라진다.
3. **결과 CSV에 재현 정보를 열로 넣는다** — 어느 노트북을 어떤 순서로 눌렀는지, 원본 파일이 어디 있는지. 행만 남으면 반년 뒤에 다시 못 돌린다.
4. **완주하지 못한 조건도 행으로 남긴다.** "죽었다"와 그때의 값을 함께 적는다. 지우면 그 자리가 어디인지 알 수 없다.

## 환경

돌린 환경을 `README.md`의 설정 표에 적는다. GPU 이름과 메모리, 프레임워크 판, 시드까지다. **환경이 바뀌면 같은 코드도 값이 흔들린다.**
